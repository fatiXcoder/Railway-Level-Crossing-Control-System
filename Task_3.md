# Task 3 — Identify Constraint Violations

| Violation ID | Constraint                              | Violation Scenario                                       | What Went Wrong?                                                    | How Do We Know It Is Violated?                                              |
| ------------ | --------------------------------------- | -------------------------------------------------------- | ------------------------------------------------------------------- | --------------------------------------------------------------------------- |
| V1           | `Train_Present → ¬Barrier_Open`         | `Train_Present = TRUE`<br>`Barrier_Open = TRUE`          | A train is present but the barrier is open.                         | The constraint requires the barrier not to be open when a train is present. |
| V2           | `Train_Approaching → Barrier_Closed`    | `Train_Approaching = TRUE`<br>`Barrier_Closed = FALSE`   | An approaching train was detected but the barrier did not close.    | The constraint requires the barrier to be closed.                           |
| V3           | `Train_Approaching → Warning_Light_On`  | `Train_Approaching = TRUE`<br>`Warning_Light_On = FALSE` | A train is approaching but the warning light is OFF.                | The constraint requires the warning light to be ON.                         |
| V4           | `Train_Approaching → Audible_Alarm_On`  | `Train_Approaching = TRUE`<br>`Audible_Alarm_On = FALSE` | A train is approaching but the audible alarm is OFF.                | The constraint requires the audible alarm to be ON.                         |
| V5           | `Train_Passing → Barrier_Closed`        | `Train_Passing = TRUE`<br>`Barrier_Closed = FALSE`       | The train is passing but the barrier is not closed.                 | The barrier must remain closed while the train is passing.                  |
| V6           | `¬Train_Cleared → ¬Barrier_Open`        | `Train_Cleared = FALSE`<br>`Barrier_Open = TRUE`         | The train has not been confirmed as cleared but the barrier opened. | The barrier must not open until the train is confirmed clear.               |
| V7           | `Sensor_Failure → ¬Unsafe_Barrier_Open` | `Sensor_Failure = TRUE`<br>`Unsafe_Barrier_Open = TRUE`  | A sensor failed and the system allowed an unsafe barrier opening.   | Sensor failure must not result in an unsafe barrier opening.                |
| V8           | `Barrier_Failure → Safety_Warning_On`   | `Barrier_Failure = TRUE`<br>`Safety_Warning_On = FALSE`  | A barrier failure occurred but no safety warning was activated.     | The constraint requires the safety warning to be ON after barrier failure.  |
